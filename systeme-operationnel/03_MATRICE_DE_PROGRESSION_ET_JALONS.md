# 📊 Matrice de Progression Pédagogique & Jalons de Compétences
> **Académie OPAYS • Système Opérationnel**  
> *Le cadre de validation des compétences en 4 paliers d'autonomisation (De l'Apprenti au Bâtisseur de Systèmes).*

---

## 1. 🪜 Les 4 Paliers d'Évolution de l'Apprenant

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│ PALIER 1 : L'UTILISATEUR ÉCLAIRÉ (Semaines 1-2 • Fin Bloc 1)                    │
│ ➔ Comprend le fonctionnement réel de l'IA sans fantasme.                        │
│ ➔ Maîtrise la méthode C.O.R.E. et extrait des données fiables de ses documents. │
│ ➔ Livrable clé : Boîte de 5 prompts C.O.R.E. + Synthèse de document complexe.   │
├─────────────────────────────────────────────────────────────────────────────────┤
│ PALIER 2 : LE CONSTRUCTEUR DE MÉTHODES (Semaines 3-4 • Fin Bloc 2)             │
│ ➔ Transforme ses tâches répétitives en Skills formalisés et réutilisables.      │
│ ➔ Configure son premier Assistant spécialisé avec son fichier Agent.md.         │
│ ➔ Livrable clé : 2 Skills documentés + Fichier Agent.md opérationnel.           │
├─────────────────────────────────────────────────────────────────────────────────┤
│ PALIER 3 : L'ARCHITECTE D'AGENTS & SÉCURITÉ (Semaines 5-6 • Fin Bloc 3)        │
│ ➔ Assemble un Agent IA complet, paramètre les outils et maîtrise les risques.   │
│ ➔ Remonte aux sources primaires et applique l'anonymisation préalable.          │
│ ➔ Livrable clé : Agent IA V2 homologué aux 5 tests + AI Safety Card signée.     │
├─────────────────────────────────────────────────────────────────────────────────┤
│ PALIER 4 : LE PROFESSIONNEL AUGMENTÉ (Semaines 7-8 • Fin Bloc 4)               │
│ ➔ Automatise ses flux de travail tout en conservant le contrôle humain souverain.│
│ ➔ Soutient son système IA devant le jury et démontre un ROI mesuré en heures.  │
│ ➔ Livrable clé : « My AI Work System » soutenu + Certification Pratique.        │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 🎯 Règles de Réajustement & Tutorat d'Appui
* Si un apprenant manque un jalon hebdomadaire $\rightarrow$ Le formateur programme un créneau d'appui de 15 minutes lors de la permanence du Samedi.
* Un devoir incomplet n'est pas sanctionné par une note chiffrée, mais renvoyé avec un commentaire d'amélioration : *« Précise ta règle dans Agent.md et re-teste le cas incomplet. »*
