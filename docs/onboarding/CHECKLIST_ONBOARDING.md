# ✅ Checklist d'Onboarding — Cohorte OPAYS Academy

> **Responsable** : équipe pédagogique. **Période** : J-10 → J0 (semaine 0).

## J-10 : Préparation de la classe
- [ ] Créer la classe Google Classroom « OPAYS Academy — Cohorte N°XX » (code : OPAYS-XX)
- [ ] Créer les 13 thèmes (voir `docs/classroom/BLUEPRINT_CLASSROOM.md`)
- [ ] Générer le kit de lancement : `node scripts/generate_classroom_posts.js [DATE-DÉBUT] --out docs/classroom/posts/cohorte-XX`
- [ ] Copier les textes des posts dans Classroom (ressources programmées + devoirs)
- [ ] Dupliquer le template AI Work Kit → 1 copie par apprenant (modèle : `docs/work-kit/TEMPLATE_MON_AI_WORK_KIT.md`)
- [ ] Créer le formulaire Diagnostic Initial (Google Forms, 5 min)
- [ ] Préparer le tableur de suivi de cohorte (`docs/cohortes/SUIVI_COHORTE_TEMPLATE.csv` → Google Sheets)
- [ ] Vérifier le lien Meet permanent (épinglé dans le Thème 00)

## J-5 (mercredi) : Bienvenue
- [ ] Envoyer l'email de bienvenue (`docs/onboarding/EMAIL_BIENVENUE.md`) avec lien Classroom + code
- [ ] Envoyer l'invitation Classroom aux inscrits

## J-3 (vendredi) : Accès outils
- [ ] Vérifier la création/accès aux comptes outils IA (ChatGPT / Claude / Gemini)
- [ ] Recenser les blocages (email professionnel, numéro de téléphone, etc.) → solutions alternatives

## J-2 (samedi) : Diagnostic
- [ ] Rappel de remplissage du Diagnostic Initial
- [ ] Vérifier que chaque apprenant a ouvert son AI Work Kit

## J0 (lundi) : Dernière ligne droite
- [ ] Vérification technique collective (micro, caméra, connexion Meet)
- [ ] Confirmer la présence des ressources Semaine 1 (programmées à 06h00, visibles)
- [ ] Envoyer l'annonce de bienvenue sur le Stream Classroom
- [ ] ✅ COHORTE PRÊTE — « La cohorte XX commence demain »

## Rappels hebdomadaires (rituel du formateur, 15 min)
- [ ] Lundi : vérifier la publication automatique des ressources de la semaine
- [ ] Mardi : séance avec le Dashboard Formateur (timer, notes, prompts)
- [ ] Jeudi 21h : vérifier la publication automatique du devoir
- [ ] Samedi : permanence déblocage
- [ ] Lundi 23h59 : collecte des remises → mise à jour du tableur de suivi (jalons)

## Bloquants connus (prévoir des solutions)
| Bloquant | Solution |
|---|---|
| Pas de numéro de téléphone pour créer un compte IA | Utiliser Gemini (compte Google) ou un outil alternatif |
| Connexion internet instable | Replays publiés sous 1h dans le Thème 01 ; missions asynchrones possibles |
| Email professionnel bloquant les invitations | Ajouter manuellement l'email personnel ; demander l'autorisation IT |
