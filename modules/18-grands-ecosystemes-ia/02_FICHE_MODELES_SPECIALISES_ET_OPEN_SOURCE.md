## 1. ⚖️ Propriétaire vs Open-Weight (Modèles Ouverts)

```
┌────────────────────────────────────────────────────────────────────────┐
│ MODÈLE PROPRIÉTAIRE CLOUD (OpenAI, Anthropic, Google)                  │
│ ➔ Avantages  : Clé en main, puissance maximale, mises à jour auto.     │
│ ➔ Limites    : Données transitant par des serveurs tiers, coût d'abonnement.│
├────────────────────────────────────────────────────────────────────────┤
│ MODÈLE OPEN-WEIGHT / LOCAL (Mistral, Llama, Qwen exécutés sur Ollama) │
│ ➔ Avantages  : 100% CONFIDENTIEL, fonctionne sans connexion Internet,  │
│                aucune fuite de données hors de l'institution.          │
│ ➔ Limites    : Nécessite du matériel informatique dédié.               │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. ⚡ Les 5 Super-Pouvoirs des Modèles Spécialisés

| Famille de Spécialité | Ce qu'elle fait de mieux | Exemples d'outils de référence |
| :--- | :--- | :--- |
| **🧠 Raisonnement Pur** | Décompose pas à pas des problèmes logiques ou d'audit financier complexes. | OpenAI o1, DeepSeek-R1 |
| **📚 Contexte Géant** | Avaler un code de lois ou 500 pages de contrats d'un coup sans perte. | Gemini 1.5 Pro, Claude 3.5 |
| **🔍 Recherche & Faits** | Moteur de recherche avec traçabilité et liens directs vers les sources. | Perplexity AI, Gemini Search |
| **💻 Code & Automatisation** | Écrire des scripts, corriger des fichiers Excel complexes, développer. | Codex, Claude Code |
| **🎨 Multimodalité & Médias** | Transformer du texte en diaporamas, visuels, voix naturelle et vidéos. | Gamma App, Midjourney, ElevenLabs |
