# 📄 Fiche Synthèse — Outils, Connecteurs & MCP
> **Académie OPAYS • Module 09**  
> *Comprendre comment connecter l'IA à votre écosystème de travail sans devenir développeur (1 page).*

---

## 1. 💡 Le Principe Fondamental
> **« Le modèle de langage est le cerveau. Les outils sont ses mains. Les connecteurs sont ses ponts. Et MCP est la prise universelle qui permet de brancher le tout facilement. »**

---

## 2. 🏛️ Le Trio Démystifié

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. L'OUTIL (Tool) : La Capacité d'Action                               │
│    ➔ Ce que l'IA sait utiliser pour agir : rechercher sur le web,     │
│       exécuter un calcul, lire un fichier, générer un visuel.          │
├────────────────────────────────────────────────────────────────────────┤
│ 2. LE CONNECTEUR (Connector) : Le Pont vers un Service                 │
│    ➔ Le lien sécurisé entre l'IA et une application externe :          │
│       Google Drive, Gmail, WhatsApp, Notion, CRM, Logiciel de paie.   │
├────────────────────────────────────────────────────────────────────────┤
│ 3. LE STANDARD MCP (Model Context Protocol) : La Prise Universelle     │
│    ➔ Un standard ouvert qui permet à n'importe quel assistant ou agent │
│       d'accéder à n'importe quel outil ou base de données sans devoir  │
│       recoder une intégration sur-mesure à chaque fois.               │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 3. 🔌 L'Analogie du Port USB-C

* **Sans standard (Le monde d'avant)** : Chaque fabricant de téléphone avait son chargeur propriétaire. Si vous changiez d'outil, il fallait tout réécrire.
* **Avec MCP (Le monde moderne)** : Comme le port **USB-C**, une entreprise peut créer un serveur MCP pour ses données internes (ex: la base des textes juridiques du ministère), et n'importe quel agent (Claude, ChatGPT, Gemini, etc.) peut s'y brancher immédiatement et de façon sécurisée.

---

## 4. 🔗 La Chaîne Opérationnelle d'un Agent Connecté

```
[ UTILISATEUR ]
       │
       ▼ (Demande : « Prépare mon dossier client »)
[ AGENT IA + AGENT.MD ]
       │
       ▼ (Appelle le Skill « Synthèse Client »)
[ SKILL MÉTIER ]
       │
       ▼ (Mobilise l'Outil de recherche)
[ TOOL : RECHERCHE BASE CLIENTS ]
       │
       ▼ (Passe par le protocole universel)
[ PROTOCOLE MCP / CONNECTEUR SÉCURISÉ ]
       │
       ▼ (Extrait l'information réelle)
[ BASE DE DONNÉES / DOSSIER GOOGLE DRIVE ]
       │
       ▼ (Restitution du livrable prêt à valider)
[ LIVRABLE FINAL DESTINÉ À L'HUMAIN ]
```
