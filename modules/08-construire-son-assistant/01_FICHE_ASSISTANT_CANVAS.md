> **Académie OPAYS • Module 08**

---

## 1. 🏛️ L'Assistant Canvas (L'Identité de votre Assistant)

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. NOM DE L'ASSISTANT : (ex: Assistant Rédaction Administrative)       │
├────────────────────────────────────────────────────────────────────────┤
│ 2. MISSION PRINCIPALE : Ce qu'il doit accomplir pour vous              │
├────────────────────────────────────────────────────────────────────────┤
│ 3. CONTEXTE DE TRAVAIL: Votre service, votre secteur, votre pays (RDC) │
├────────────────────────────────────────────────────────────────────────┤
│ 4. RÈGLES PERMANENTES : Les lois inviolables (Ton, concision, rigueur) │
├────────────────────────────────────────────────────────────────────────┤
│ 5. SKILLS EMBARQUÉS   : Les capacités réutilisables qu'il maîtrise     │
├────────────────────────────────────────────────────────────────────────┤
│ 6. MÉMOIRE DE TRAVAIL : Ce qu'il retient sur vos préférences           │
├────────────────────────────────────────────────────────────────────────┤
│ 7. LIMITES STRICTES   : Ce qu'il a l'interdiction formelle de faire    │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. 🧠 Contexte vs Mémoire : La Règle d'Or

```
┌───────────────────────────────────────┬───────────────────────────────────────┐
│ LE CONTEXTE (L'Information Ponctuelle)│ LA MÉMOIRE (La Connaissance Durable) │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • Ce que vous donnez pour la tâche    │ • Ce que l'assistant retient dans le  │
│   en cours (le document du jour).     │   temps sur votre façon de travailler.│
│ • Exemple : « Voici le projet de loi  │ • Exemple : « Mon service utilise     │
│   sur lequel nous travaillons ce matin»│   toujours la police Arial 11 et une │
│                                       │   formule protocolaire spécifique. »  │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

---

## 3. 🚦 La Matrice de Mémoire en 3 Catégories

| Catégorie | Exemples concrets | Comportement à adopter |
| :--- | :--- | :--- |
| 🟢 **À Mémoriser** | Vos préférences de mise en page, l'intitulé exact de votre service, le ton formel attendu. | Enregistrer dans les instructions permanentes ou dans la mémoire du compte. |
| 🟡 **À Fournir Ponctuellement** | Les notes de la réunion d'hier, les chiffres d'un devis en cours, le texte d'un courrier reçu. | Charger en pièce jointe ou coller dans le chat à chaque session. |
| 🔴 **À NE JAMAIS MÉMORISER** | Mots de passe, numéros de comptes bancaires, secrets d'État, dossiers médicaux. | **Interdiction formelle de stockage.** Anonymiser systématiquement avant tout traitement. |
