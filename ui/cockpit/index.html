Inscriptions

Candidatures reçues du Google Form officiel — vérification, paiement (humain), admission, puis apprenant. Le formulaire reste le point d'entrée public.

Voir le Google Form

Chargement des candidatures…

Candidature ≠ paiement ≠ admission ≠ apprenant : chaque étape est une action humaine distincte. Le paiement n'est jamais automatique — marquer « PAYÉ » exige le montant réellement reçu.

Apprenants

— — personnes admises ou importées, avec leur état Classroom. Cliquez une ligne pour ouvrir la fiche 360°.

Chargement…

Importer les apprenants

Chaque ligne crée un compte apprenant avec un mot de passe initial généré, affiché une seule fois. Format avancé JSON également accepté (tableau d'objets {name, email}).

Inviter les apprenants dans Classroom

Chargement…

L'invitation utilise la liste réelle des apprenants importés — pas une liste ressaisie. Si le serveur bloque les invitations (droit Google manquant), le motif exact est affiché ici.
